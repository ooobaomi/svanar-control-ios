# SVANAR Control Android 1.3

Android 8+ 本地蓝牙伴侣，无互联网权限，日常使用不需要 root。

## 使用
在系统蓝牙中连接耳机音频，双耳唤醒，关闭其他电脑／手机的耳机控制连接，再扫描连接。
App 切至后台或打开系统文件选择器会断开控制，音频不受主动断开；返回后重新扫描连接。

## EQ 收藏和文件
保留 14 组内置偏好预设，均非测量校准。滑块和预设先编辑草稿，点击应用才写耳机。
展开“收藏与联动”，可命名保存、载入草稿、覆盖、重命名、删除，最多 64 套收藏。
导出包含收藏、频段定义和模式绑定。通过 Android 文件选择器选择导入／导出位置，不需要全部文件访问权限。
JSON 文件上限 64 KiB，增益须为 10 段整数、每段 ±10 dB。错误版本、无效频段、分数增益、未知绑定和过深嵌套均拒绝。
导入合并，不覆盖同 ID 的不同内容；自动联动始终关闭，导入不立即改耳机。
附带的 SvanarControl-EQ-14-presets.json 可将内置 14 组曲线加入收藏，不预设模式绑定。

## 模式与 EQ 联动
选中收藏，分别绑定 HiFi／降噪／通透，再显式勾选“模式变化时应用绑定 EQ”。
App 切模式会应用对应曲线并查询全部 10 段确认。耳机手动模式变化在前台连接期间约每 5 秒检测。
首次连接仅读取，不应用联动；未绑定的模式不改 EQ。删除收藏会清理相应绑定。
App 内模式切换联动已实测；耳机长按触发联动的端到端实测：未执行。

## 触控重映射
读取成功才开放耳机返回的耳侧和手势。支持映射播放、切歌、音量、语音助手、模式和通话动作。
首次写入前，按耳机身份持久保存原映射；每次写入后重新查询，检查目标及其他手势；提供恢复原映射按钮。
当前 S050 固件在通透、HiFi 下两次触控 GET 查询均无响应，控制连接随后按超时策略断开。
因此本机触控写入及恢复实测：未执行，按钮保持禁用；未发送任何触控设置包。
复现：保持双耳唤醒并连接控制 → 点击“读取触控映射”；收到有效映射后再展开设置。
备份／写入代码已加入，但不将通用协议支持当成本耳机已支持。

## 降噪／通透强度
点击“检查降噪 / 通透强度能力”重新查询。
本机当前功能响应 01 01 01 00 00 00；模式档位响应 00 00 01 00 02 00。
降噪、通透强度均未声明支持，档位字段均为 0；未开放强度滑块，未写未知档位值。
现有 HiFi／降噪／通透三种模式切换不受影响。不会用 EQ 或音量变化冒充强度。

## 其他功能
左右耳电量、系统媒体音量与静音、游戏模式回读确认、型号／固件／编码诊断均保留。
LDAC 能力声明不等于当前协商成功；此前选择 LDAC 后系统仍为 AAC 44.1 kHz / 16 bit。

## 构建
Windows PowerShell、JDK、Android SDK android-35 和 build-tools 36.0.0。
运行 build.ps1，可通过 -Sdk、-Java、-SigningStore 指定绝对路径。
不指定签名路径时生成本地开发签名；升级旧安装需使用同一签名。签名私钥不随源码交付。
构建包含 CRC、EQ、触控格式和能力解析测试；启动时另运行 Android 原生 JSON 解析自测。
