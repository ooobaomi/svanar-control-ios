# Android 1.3.0

原生 Android 8+ 伴侣，APK 与已安装在测试手机上的 v1.3 使用同一开发签名。

- 14 组 EQ 预设、多套收藏、JSON 导入导出、模式与 EQ 联动（默认关闭）。
- 模式切换与 EQ 写入均查询回读。安卓手机实测过收藏、文件往返、非法文件拒绝及 App 模式切换联动。
- 游戏模式、左右耳电量、固件和编码能力诊断。
- 触控模块以有效映射回读为启用前提；当前 S050 查询无响应，未执行触控写入。
- 当前 S050 未声明降噪／通透强度调节，档位 0，未开放强度滑块。
- 没有固件刷写功能；已停止固件研究。

这里发布的是本机已编译并完成签名校验的 APK，云端检查文件 SHA-256 和 APK 容器，不冒充一次新的 Android 源码构建。
