# SVANAR Control Windows 1.3

Windows 10/11 x64 本地蓝牙耳机伴侣；无需安装 Python 或管理员权限，不含固件刷写。
解压整个成品 ZIP 后运行 SvanarControl.exe，保留同目录的 _internal 文件夹，不要只拷贝 EXE。

## 功能
- 保留 Windows 耳机音量、静音、保存恢复音量、默认输出选择和恢复。
- HiFi／降噪／通透三模式，10 段硬件 EQ，每段 ±10 dB；写入后查询确认。
- 14 组偏好预设（非测量校准）；多套收藏、重命名、覆盖、删除；三端兼容的 EQ JSON 导入导出。
- 显式模式/EQ 绑定与可关闭联动：默认关闭，首次连接只读，未绑定模式不改 EQ。
- 游戏模式开关、左右耳电量、型号／固件／耳机编码能力诊断。
- 按有效映射读回开放的触控设置及原映射备份恢复。当前 S050 触控查询曾两次无响应，不声称已解锁。

## 使用
先在 Windows 配对耳机音频，关闭手机／其他电脑的耳机控制接口，唤醒双耳，再点击重新连接。
EQ 预设和滑块只编辑草稿，点击应用才写耳机。收藏和导入不会立即改耳机。
在“收藏 / 文件 / 联动”中绑定模式，并显式开启联动；连接期间约每 5 秒检测耳机模式变化。
首次连接只读，不会因已有绑定立即改 EQ。导入后关闭联动；同 ID 不同内容保留为新收藏。
文件上限 64 KiB、64 套收藏，固定 10 个整数增益；小数、布尔值、越界和无效绑定均拒绝。

## 数据和设备边界
配置位于本用户 LocalAppData 的 SvanarControl 目录。旧 settings.json 和 eq.json 保留；新收藏使用 profiles.json。
首次触控修改前按耳机身份原子保存原映射；查询失败则保持禁用。当前没有触控灵敏度设置入口。
当前 S050 降噪／通透强度标志和档位均为 0，不开放虚假强度滑块。EQ 和音量不等于环境声强度。
编码页只显示耳机报告，不将 LDAC 能力声明当作 Windows 正在使用 LDAC。
蓝牙事务超时会断开控制，避免迟到响应串包；不会主动切断音频。

## 构建和测试
原打包环境为 Python 3.15 x64；依赖见 requirements.txt 与 requirements-build.txt。
安装依赖后运行 build.ps1，可用 -Python、-DistDir、-WorkDir 指定路径。
脚本运行离线回归，打包 one-directory EXE，并在隔离的数据目录执行隐藏界面启动检查。
单独离线测试：python -m unittest discover -s . -p "test_*.py" -v。
离线模拟测试不等于耳机实机测试；当前强度写入、触控写入／恢复未实测，不会伪装成已支持。
