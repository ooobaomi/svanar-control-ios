# Windows v1.3.0

Windows 10/11 x64，下载 ZIP 后完整解压，运行 SvanarControl.exe；保留 _internal 文件夹。无需安装 Python。EXE 未做代码签名。

新增 14 组 EQ 预设、收藏管理、三端兼容 JSON 导入导出、显式模式/EQ 绑定和默认关闭的联动；游戏模式、左右耳电量和能力诊断；按有效映射开放的触控设置与原映射备份逻辑。保留系统音量和默认输出功能。

已通过 19 项离线单元测试、隐藏 Tk 界面构造回归和打包后 EXE 启动检查。当前版本现场测试未发现耳机控制广播，未建立连接、未写入耳机，新增联动的 Windows 实机验证尚未完成。

S050 既往触控查询无响应，触控写入/恢复未实测；降噪/通透强度未声明支持，不开放虚假滑块。编码报告不等于 LDAC 已协商。不含固件刷写。
